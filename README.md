# Weather Web App

A simple Weather Application built as a web development practice project

---

##  Project Overview
This project was created to practice essential front-end web development skills, including styling UI components, implementing flexbox layouts, and building responsive visual cards.

---

##  Features
* **City Search:** Search interface with an input box and submit button.
* **Weather Metrics:** Displays temperature, city name, humidity percentage, and wind speed.
* **Error Handling:** Includes UI elements to alert users of invalid city entries.
* **Modern UI:** Styled with gradient card design and clean layout adjustments.

---

## Built With
* **HTML5:** Markup for structure and weather components.
* **CSS3:** Styling using Google Fonts (Poppins), custom gradients, and Flexbox layouts.

---

## Getting Started
1. Clone or download the project files.
2. Open `index.html` directly in your web browser.
